# Правила для этой папки

Сайт шиномонтажа «Колесо 93». Статика, GitHub Pages, без сборки.

**Перед любой правкой прочитай `HANDOFF.md`.**

Коротко, что нельзя:

- выдумывать товары, бренды и цены — данные только из `data/товары.json`;
- ставить заглушки вида `via.placeholder.com` и «примерные позиции»;
- писать «в наличии» — наличие уточняется у менеджера;
- трогать домен, DNS и OpenCart клиента;
- менять цену и состав работ, зафиксированные в `HANDOFF.md`.

Проверка перед сдачей: открыть страницу в браузере, посмотреть консоль, пройти фильтры и корзину, посмотреть на ширине 390 px.
